# 実例索引(ロボットアームシミュレータ設計の実録)

すべて実際のコンサルティング対話から生まれた成果物。連番は反復の記録であり、
**バージョン間の差分そのものが教材**(何を引っかかりとして仕込み、ユーザーの
どんな違和感が改訂を生んだか)。作る成果物のタイプに応じて、該当する1〜2点を
view してから着手すること。全部読む必要はない。

## レイアウトワイヤー系(robot-arm-wireframe-*)

- **robot-arm-wireframe.html (v1)** — 初回ワイヤーの基本形。ゾーニング(メニュー/左=入力/
  中央=3D/右=出力/下=タイムライン)、注釈の書き方、慣習記法(ハッチ、◆、再生ヘッド)の見本。
  → 初めてレイアウトワイヤーを作るとき参照。
- **robot-arm-wireframe-v2.html** — 選択モデルの導入。階層ツリー追加、コンテキスト依存パネル、
  代表状態(RobotArm選択中)の描き方、入力可/表示のみの見た目の区別。
  「左下パネルの責務重複」という引っかかりを注釈内に仕込んだ例でもある。
- **robot-arm-wireframe-v3.html** — 引っかかりの回収。左下パネル廃止、ハイブリッドウィジェット
  (スライダー内蔵数値フィールド)、「左=選ぶ、中央=触る、右=編集」への収斂。
  v1→v3の変遷を振り返る文の書き方も参考になる。
- **robot-arm-wireframe-v4.html** — KPI HUD(トレードオフ指標の同時表示)、ポーズのスコープ再判定
  による移設、モーダル(テンプレートインベントリ)を実際に開閉できる形で入れた例。
  スコープ×頻度マトリクスの総まとめ段階。
- **robot-arm-wireframe-v5.html** — 座標系。シーングラフ(マウント=親子付け替え)、
  ◇マウントポイント、基準ドロップダウン、格納/表示の分離、赤X緑Y青Zの軸表示。
  → 3D/空間系ツールの設計時に参照。

## フロー/ウィザード系(optimization-wizard-flow-*)

- **optimization-wizard-flow.html (v1)** — フローのワイヤーの基本形。制約の漏斗(5ステップ)、
  ステップインジケータ、パレート候補選択、確定文脈の常時表示、ステップ別注釈の仕組み。
  → ウィザードを初めて作るとき参照。
- **optimization-wizard-flow-v2.html** — 語彙設計の実例。「必要リーチ」(解決領域)を
  「どこからどこへ+個/時」(問題領域)に書き換え、導出値のエコーバック、
  穴埋め文型、詳細設定への段階的開示。before/afterの差分が最良の教材。
- **optimization-wizard-flow-v3.html** — ワークベンチ同居型ウィザード。左パネル+右ビュー連動
  (フィードフォワード)、ステップごとのハイライト/ゴースト/境界枠の切替実装、
  「3D化できる情報とできない情報」の使い分け。
  → メインビューと併走する可視化を設計するとき参照。

## モード設計系(template-*)

- **template-edit-mode-wireframe.html** — クラス編集の隔離モード。パンくず+テーマ色(紫)+
  影響範囲開示(使用状況/全インスタンスに反映)、ジオメトリ候補点によるマウントポイント生成、
  「このモードにはローカルしかないので基準切替UIが消える」という概念削減の実例。
- **template-compose-wireframe.html** — プリミティブ合成による新規テンプレート作成。
  drawioイディオム(左パレットからドラッグ)の移植、グループ化=シーングラフ中間ノード、
  整列スナップガイド、visual/collision の役割分離。
  → 既存ツールのイディオム移植を設計するとき参照。
