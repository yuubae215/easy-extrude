v3 → v4 の変更点(3件。すべて「編集の住所は所有権で決まる」という訂正からの帰結)
① 「自分は誰か」を状態にした。これまでアプリに currentActor は存在しなかった (uiStore.js:158 の personaFilter は persona projection highlight —— 見た目を減光するだけで書き込みを一切ゲートしない)。ヘッダに視点の主体を置き、 自分の主張だけが入力可・他人の主張は 🔒 読み取り専用にした(編集可否を見た目で区別:入力可=枠+内側の影、表示のみ=枠なし)。
② 3D に未解決エンティティのハイライト。d_ref を選ぶと、それが束縛している実体 (Robot / Conveyor)が 3D で ⚠ 表示になる。これで「どの変数が揉めているか」が 左パネルのトグルに依存せず届く —— 3D ビューは [幾何]/[意味] のどちらを見ていても隠れないから。
③ 場が小さくなった。場は「変える場所」ではなく合意する場所。編集は所有権があればどこでも起こる (3D ドラッグ = createEditAdmissibleCommand で既に実装済み。モードに閉じ込められているだけ)。 訂正:v1〜v3 は「発見/解消」の 1 軸で切って編集を場に寄せていた。正しくは 所有権(誰が書けるか)と合意の必要性(場に行くか)は直交する 2 軸。

⚠ v4 に残した引っかかり(次の反復のタネ)
①「自分」の基数 N が未対応です。ヘッダの[自分]は 0(未設定)と 1(1人のロール)しか表現できません。 でも小さいチームでは1人が robot_eng と mech_eng を兼ねるのは普通です。兼務者は 「今どちらとして書いているか」を毎回選ぶのですか? それとも両方の行が同時に編集可になりますか? ——ROBOT_CARDINALITY(none/single/multi, ADR-090)と同じ形の穴で、 あのときは台帳の基数列が空だったのが欠陥でした。
②「自分」はどこに保存されますか? 文書(.ctx.json)に入れると、ファイルを渡した相手も あなたとして書けてしまう。ブラウザに入れると、同じ人が別の端末で開いたとき誰でもなくなる。 これは設定ですか、それとも文書の一部ですか?
③ 3D で Robot を動かすと robot_eng の主張が書き換わります。では vision_eng として名乗っている人が Robot を動かしたら? 動かせないのか、 動かせるが主張は書き換わらないのか、警告が出るのか。幾何の編集権と主張の編集権は 同じものですか?
